# Q1 – Serverless Image Upload Workflow

## 1. Project Overview

This project implements a serverless image-upload workflow using Amazon S3, AWS Lambda, and Amazon CloudWatch Logs.

When an image is uploaded to an Amazon S3 bucket, an S3 ObjectCreated event automatically invokes the AWS Lambda function. The Lambda function extracts details of the uploaded object and records the execution information in Amazon CloudWatch Logs.

3. AWS Services Used

The following AWS services are used in this project:

Amazon S3
AWS Lambda
Amazon CloudWatch Logs
AWS IAM

4. Components
4.1 Amazon S3

Amazon S3 is used to store the uploaded image.

Bucket Name:

q1-s3-lambda-image-upload-2026

AWS Region:

ap-south-1 (Asia Pacific - Mumbai)

Purpose:

Stores the uploaded image.
Generates an ObjectCreated event when an image is uploaded.
Sends the event to the configured AWS Lambda function.
4.2 AWS Lambda

Lambda function name:

Q1-S3-Image-Logger

Runtime:

Python

Purpose:

Receives the S3 ObjectCreated event.
Extracts information about the uploaded object.
Prints the extracted details.
Records execution information in CloudWatch Logs.

The Lambda function extracts the following object details:

Event Name
Event Time
Bucket Name
Object Key / File Name
Object Size
ETag
Lambda Request ID
4.3 Amazon CloudWatch Logs

Amazon CloudWatch Logs is used to store and view the execution logs generated by the Lambda function.

Purpose:

Records Lambda execution information.
Displays the S3 event details.
Helps verify successful Lambda execution.
Provides a way to monitor and troubleshoot the function.
4.4 AWS IAM

AWS IAM is used to provide the required permissions for AWS Lambda execution and CloudWatch logging.

Purpose:

Allows Lambda to execute using its execution role.
Allows the function to write execution logs to CloudWatch Logs.

5. Workflow

The complete workflow is as follows:

The user uploads an image to the Amazon S3 bucket.
Amazon S3 detects the object creation event.
An ObjectCreated event is generated.
The event automatically invokes the AWS Lambda function.
The Lambda function receives the S3 event information.
Lambda extracts the uploaded object's details.
The extracted information is written to CloudWatch Logs.
The execution is verified through the CloudWatch log stream.
